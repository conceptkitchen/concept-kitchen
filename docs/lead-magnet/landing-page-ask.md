## TECH OPTIONS

| Platform | Pros | Cons |
|----------|------|------|
| **Carrd** | $19/yr, simple, fast | Limited customization |
| **Framer** | Beautiful, free tier | Learning curve |
| **Typedream** | Notion-like, easy | Less control |
| **ConvertKit Landing Page** | Built into email tool | Basic design |
| **Webflow** | Full control | Overkill for one page |

**Recommendation:** Carrd or ConvertKit landing page — fast, cheap, done.
